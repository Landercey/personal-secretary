# 被杀毒软件误报？怎么申诉（附现成文案）

## 先看清两件事

1. **是哪个文件被吃**：Windows 安全中心 → 病毒和威胁防护 → **保护历史记录**，
   里面会写清文件名、检测名（形如 `Trojan:Win32/Wacatac.B!ml`）和路径。
   把"检测名"记下来，申诉要用。
2. **先自己能跑起来**：还原文件 + 把整个软件文件夹加进「排除项」
   （README 的「被杀软隔离了怎么办」有图文步骤）。申诉是"让别人也别再被拦"，
   不解决你眼前这一台。

## 去哪儿申诉

<https://www.microsoft.com/en-us/wdsi/filesubmission>

选 **Software developer**（作者本人提交），然后：

- **File**：上传 `私人秘书.exe`（或被杀的那个文件）。
  超过 100 MB 就先压成 zip，在说明里写清楚。
- **What do you believe this file is?** → *Incorrectly detected as malware*
- **Detection name**：填你在"保护历史记录"里看到的那个名字。

## 直接粘的文案（英文）

```text
This is my own open-source desktop tool, packaged with PyInstaller (onedir).
It is not malware and I am the author.

What it does: it reads messages from the user's own QQ groups (via a local
NapCat/OneBot client) and turns them into a local to-do list, then pushes a
daily digest to the user's own WeCom group bot. Everything runs locally on the
user's Windows machine; the only network traffic is the user's own configured
endpoints and GitHub for downloading NapCat on first setup.

Source code (public, MIT-style licence pending):
https://github.com/Landercey01/personal-secretary
Version: see build-info.txt next to the exe.

Why it is likely flagged: it is an unsigned PyInstaller bundle, and at the
user's explicit request it downloads and runs the official NapCat/QQ installer.
That download-then-run pattern is what the heuristic rules react to.

Please re-check this file and remove the false positive.

SHA256: <把下面命令的输出粘在这里>
Detection name reported by Windows Security: <上面记下来的检测名>
```

## 文件指纹怎么拿

```bat
certutil -hashfile 私人秘书.exe SHA256
```

（每次重新打包指纹都会变 —— 所以**每次发新版如果又被误报，要重新提一次**。）

## SmartScreen 的"Windows 已保护你的电脑"

那是另一套（不是杀毒判定，而是"这个发布者不熟"）。同一个网址可以选
**SmartScreen** 提交，或者在提醒框里点「更多信息」→「仍要运行」。

## 想一劳永逸

买一张**代码签名证书**（便宜的个人版几十美元/年，OV 组织版几百美元/年），
给 exe 签名之后再打包。签名过的程序基本不会被启发式拦 —— 这是这类工具的通病，
国内外同类项目都躲不过。
