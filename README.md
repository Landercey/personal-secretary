# 私人秘书（personal-secretary）

把 QQ 群消息、发给小号的消息、以及手动粘贴/拖入的文件，变成待办，定时汇总推送到企业微信。

> ⚠️ **关于用哪个 QQ 号：自己权衡，风险是真的。**
>
> 本工具通过非官方方式（把 NapCat 注入 QQ）让电脑登录 QQ 来收消息。
> 腾讯随时可能限制这种登录方式，**被封的风险落在你登录的那个号上**。
>
> | | 优点 | 代价 |
> |---|---|---|
> | **小号**（推荐） | 封了不心疼 | 得先进你要监控的那些群；学院群、班级群未必让外人进 |
> | **大号** | 群都加好了，装上就能用 | 风险落在主号上 |
>
> **作者自己用的是大号**，从 2026 年 9 月下旬稳定用到现在，没出过事。
> 这是经验，**不是保证** —— 别把它当成"大号安全"的证据。
>
> 想降低风险：**只收不发**（本工具就是这么设计的，不会主动发任何 QQ 消息）、
> 只勾选真正需要监控的群、别频繁重启登录。

## 界面能干什么

打开 `python run.py --ui`（或者双击桌面的「私人秘书」），左侧一列就三件事：

| 按钮 | 干什么 |
|---|---|
| **＋ 新建待办** | 粘贴一句话，时间和地点自动认出来 |
| **⟳ 同步** | 立刻拉一遍课表订阅，变成待办 |
| **⚙ 设置** | 推送时间、企业微信 Webhook、QQ 群号、AI、课表、过滤强度……**全在这里改** |
| **📱 QQ 接收** | 启动/停止后台、扫登录二维码、开机自启 —— 点一下右栏就出来 |

左侧分组：今天 / 明天 / 本周 / 下一周 / 逾期 ｜ 全部未完成 / **已完成** / 已归档 / 废件箱。
**没写时间的待办算「今天」**——你不写时间就等于"今天要做"。不然「拿快递」
这种随手记的只有点开「全部未完成」才看得到，你会以为它丢了。
（只算进「今天」：明天/本周/逾期都不算，它没时间，凭什么算过期。）
右上角有个**搜索框**（标题、正文、地点、原话都搜得到）。
搜索**只在当前分组里找** —— 在「今天」里搜就只搜今天的，
标题旁边会写着"只在「今天」里找"。
点开一条待办能**改标题、时间和地点**（解析错了不用重新发一遍），
附件能看名字、能点「打开」，是图片还会出缩略图。
右栏右上角有个 **✕** 可以随时收起来。

**左下角会告诉你收消息的进程到底活没活**：
`✅ 登录号 xxx｜收到 42` 是正常；`⚠️ QQ 接收已经 N 分钟没动静了`（橙色）
说明那个进程没在跑或者 NapCat 掉线了 —— 这就是"我发了消息怎么没反应"的答案。

**QQ 也能从界面里管**：点左下角「📱 QQ 接收」，右栏就是那一块

- 「启动 QQ」：后台常驻（一个进程同时干**收消息 + 定时推送**两件事）
- **登录二维码直接显示在里面**（用手机 QQ 扫）。约 2 分钟过期，
  过期了点「重新出码」换一张
- 「停止后台」
- **开机自启**：开了以后每次开机它自己在后台跑，不用每天手点一次

（第一次「启动 QQ」会先自动下载安装 NapCat，约几十秒。要在
设置 → 收消息 → QQ 接入 里填一次"要登录哪个 QQ 号"。）

**全装在一个文件夹里**：程序、`data`（你的待办）、`napcat`（QQ 本体）都在
同一个目录下。**卸载 = ① 关掉开机自启 ② 删掉这个文件夹**，两步，不留东西
（设置 → 数据与资源 底部写着具体路径）。

做完的事不会消失：「已完成」分组里找得到，还能一键撤回来。
点错的「这不是待办」也找得回来：废件箱里和"被拦下的原文"放在一起，能点「恢复」。

**移出都只有一个人目的地：回到「全部未完成」。** 完成、归档、误判三种都能移出，
移出之后不用选去哪 —— 它自己按截止时间回到该去的分组（今天/本周/逾期…），
没写时间的就只在「全部未完成」里。想改到别的日子用「改内容」，那是两件事。
（废件箱里"被拦下的原文"不是待办，所以没有移出这一说。）

**把文件或一段字拖进窗口**，右边会弹出「这个怎么处理？」：
读里面的字变成待办 / 只看它写了什么 / 算了。拖进来的文件大小上限默认 12 MB
（网页拿不到真实路径，内容要摊成文本传过去），更大的用 `python run.py --file 路径`。
**从桌面拖过来的如果是快捷方式（.lnk）也没关系** —— 会自动跟到它指向的那个文件。
读不出内容时，会直接告诉你原因（旧版 Office、扫描件、不支持的格式……），
不用猜。

**能读的文件类型**：Word / PPT / Excel / PDF / 图片（系统自带 OCR）/
**压缩包（.zip，里面的文件挨个读）** / **思维导图（.xmind）**。
视频、旧版 `.doc/.ppt/.xls`、`.rar/.7z` 暂时不支持 —— 拖进去会告诉你
该怎么绕过去（比如"另存为 .pptx 再发一次"）。

**小号收件箱**（设置 → 收消息 → QQ 接入 → 小号收件箱）是**全盘接收**的：
你发给它的东西不过滤闲聊、不过滤碎片，**连文件里读出来的字也当待办**。
别的地方（群消息、别人发的文件）会严格过滤 —— 那边噪声多，不严不行。

设置面板里的每一项都带一句人话说明，改完点「保存」会**写回 config.toml**
（只改你动过的那一行，你自己写的注释不会被冲掉）。

设置分成四个标签页，不用在一长条里翻：

| 标签页 | 里面有什么 |
|---|---|
| 推送到手机 | 企业微信机器人、什么时候推 |
| 收消息 | QQ 接入、用大号还是小号、课表 |
| 看懂消息 | AI 增强、识别与过滤、文件解析 |
| 数据与资源 | 数据保留、资源占用、标题规则 |

一般不用动的东西（文件解析细节之类）折在每段底部的「高级」里。

**「AI 增强」现在只有一句说明，没有输入框** —— 那个功能还没做，现在走的是
纯规则解析（不联网、不花钱、任何内容都不会传出去）。留着框子让人填、
填完什么都不会发生，比没有这功能更糟。等做成插件，输入框会自己出现。
**监听地址、端口、路径、令牌**这四项标着「程序管着」，默认点不动 ——
它们要跟 NapCat 的配置严格一致，单方面改会让 QQ 静默收不到消息。
确实要改的话点下面的「确实要改」就能编辑。

第一次打开会弹一个风控提示：用大号还是小号，代价不一样。看完点「我知道了」就不再弹。
中间顶部还有一张"还没弄完这几步"的清单，点哪一条直接跳到对应的设置。

**时间相关的设置不会一上来就问你**：推送时间先用 07:30 / 21:30 跑着，
等你**第一次真的在手机上收到推送**之后，界面才提醒你"想换时间点就点这里"。
课表的"开学第一周"同理 —— 只有你导入的课表里真的写了单双周，才会提醒你填。

## 现在就能跑

不需要装任何东西（Windows + Python 3.11 以上即可）：

```bat
python run.py --selftest          检查契约和环境
python run.py "明天下午三点交作业"  录一条
python run.py --read 照片.jpg     只看这个文件能提出什么字，不入库
python run.py --file 作业.pptx    把一个文件变成待办
python run.py --list              看未完成
python run.py --list junk         看废件箱（没收下的原文都在这里）
python run.py --digest            生成一份汇总打印出来
python run.py --push              把汇总真正推送到企业微信
python run.py --check-push        检查推送通道配置（不发消息）
python run.py --next-push         看下一次什么时候推、有没有错过的
python run.py --schedule          启动定时推送（Ctrl+C 停止）
python run.py --setup --account 你的QQ号   只装 NapCat（约 2.5 分钟）
python run.py --deploy --account 你的QQ号  装 + 启动（先起接收端再起 QQ）
python run.py --ui                打开界面
python run.py --shortcut          在桌面建快捷方式
python run.py --check-qq          看 QQ 接入的配置和状态
python run.py --qq                启动 QQ 接收（Ctrl+C 停止）
python run.py --done 3            标记某条完成
python run.py --stats             看统计
python run.py --plugins           看装了哪些插件、哪个坏了
python run.py --sync              拉一遍课表订阅，变成待办
```

跑测试（标准库 unittest，不用装 pytest）：

```bat
python -m unittest discover -s tests -t . -v
```

## 想改代码？先看这几张地图

每个文件开头都有一张「想改这里的话，先看这张地图」，直接告诉你改什么去哪一行：

| 你想改 | 去哪 |
|---|---|
| 界面上的分组口径（今天/本周怎么算） | `app/store/repository.py` 的 `_view_filter()` |
| 设置面板有哪些项 | 不用改界面 —— 它照着 `app/runtime/config.py` 的 `DEFAULTS` 自动生成 |
| 设置面板写回配置文件 | `app/runtime/config.py` 的 `Config.set()`（按行改，不动你的注释） |
| 界面和 Python 之间能调什么 | `app/ui/bridge.py` 的 `Api` |
| 怎么判断一句话是待办 | `app/pipeline/quick_parse.py` |
| 什么样的碎片该丢掉 | `app/pipeline/quick_parse.py` 的 `is_fragment()` |
| 过滤的松紧 | `config.toml` 的 `[parse] filter_strength`（严格/宽松/关闭三档） |
| 推送长什么样 | `app/sinks/console.py` 的 `build_digest()` |
| 推送时间 | `config.toml` 的 `[push] times` |
| 错过了还补不补 | `config.toml` 的 `[push] catch_up_minutes` |
| 什么时候暂停推送 | `app/runtime/sysmon.py` 的 `busy()` |
| 加一个新的消息来源 | 新写一个 `app/sources/xxx.py`，然后在 `run.py` 的 `build()` 里注册 |
| 加一个新推送通道 | 新写一个 `app/sinks/xxx.py`，然后在 `app/sinks/router.py` 里登记 |
| 群里什么算闲聊、什么算通知 | `app/pipeline/chat_filter.py` 里的那几张词表 |
| QQ 怎么连（端口、令牌、收哪些群） | `config.toml` 的 `[qq]` 段 |
| 识别用哪个 OCR 引擎 | `config.toml` 的 `[extract] ocr_engine` |
| 支持一种新文件格式 | `app/pipeline/extract/service.py` 的 `_READERS` 加一行 |
| 多线程下数据库行为 | `app/store/repository.py` 的 `_synchronized` —— **改前先读那段注释** |

改完一定要跑一遍：

```bat
python -m unittest discover -s tests -t .
```

## 为什么值得一看

这个项目从旧版本改造而来。旧版本自己用了几个月，攒下了真实的踩坑记录，
新版本把它们全部继承下来，其中最值钱的一条：

**"经常只有时间"** —— 旧库 168 条待办里有 27 条（16%）摘掉时间后什么都不剩，
手机收到的就是 `（A组）`、`📅周一`、`10月9日-10月21日 12:20-13:50` 这种碎片。
三个根因已经定位并写进契约，第 2 步就修掉了最致命的一个（标题为空时回退成原文）。

完整清点见 [CONTRACT.md](CONTRACT.md) 第七节。

## 架构

```
[来源] ──► [理解] ──► [存储] ──► [输出]
```

四段之间**只通过契约层定义的四种数据格式通信**，不许互相 import 内部实现 ——
这条由 `tests/test_contract_integrity.py` 自动检查，破坏边界会直接测试失败。

```
app/contracts/   四种数据格式 + 五个接口
app/sources/     手动录入、QQ 群消息、小号收件箱
app/pipeline/    闲聊过滤、繁简归一、规则解析、管线
app/store/       SQLite
app/sinks/       企微群机器人、控制台
app/runtime/     配置中心（所有阈值集中在这里，代码里不写裸数字）
```
