# 私人秘书（personal-secretary）

把 QQ 群消息、发给小号的消息、以及手动粘贴/拖入的文件，变成待办，
定时汇总推送到**企业微信 / 钉钉 / 飞书 / 微信 / iPhone**（挑一个就行）。

![群消息变成待办](docs/images/before-after.png)

左边是群里的原话，右边是它挑出来的待办 —— 闲聊和没有时间点的消息不进列表。
每条都带原文片段和来源，误判了在列表里点一下就能删。（图里的消息都是编的。）

我是个还在上学的普通大学生，这是我**第一次**做开源。代码是边学边写的，能跑、有测试兜底，
但肯定有你一眼就看出来的不周到 —— 不周到的地方**我自己先列在下面了**，
你不用替我找。

现在的状态是 **Alpha**：我自己天天在用，但**只被一个朋友真机装过**。
所以你会撞到问题，这很正常，那就是它现在的样子。

撞到问题、或者哪里别扭，欢迎开 Issue 直接说 —— **带上复现步骤我改得快**；
觉得代码辣眼睛，更欢迎直接提 PR（[CONTRIBUTING.md](CONTRIBUTING.md) 里写了怎么在几分钟内跑起来）。

我不收钱、也不指望靠它出名 —— 我用它管我自己的作业、快递和开会的日子，
写它是为了让自己不受罪，顺手分享出来。**最怕的不是被骂，是没人用。**

> ⚠️ **关于用哪个 QQ 号：自己权衡，风险是真的。**
>
> 本工具通过非官方方式（把 NapCat 注入 QQ）让电脑登录 QQ 来收消息。
> 腾讯随时可能限制这种登录方式，**被封的风险落在你登录的那个号上**。
>
> | | 优点 | 代价 |
> |---|---|---|
> | **小号**（推荐） | 封了不心疼 | 得先进你要监控的那些群；学院群、班级群未必让外人进 |
> | **大号** | 群都加好了，装上就能用 | 风险落在主号上 |
>
> **我自己用的是大号**，从 2026 年 9 月下旬稳定用到现在，没出过事。
> 这是经验，**不是保证** —— 别把它当成"大号安全"的证据。
>
> 想降低风险：**只收不发**（本工具就是这么设计的，不会主动发任何 QQ 消息）、
> 只勾选真正需要监控的群、别频繁重启登录。

## 下载

去 [Releases](https://github.com/Landercey/personal-secretary/releases/latest) 拿：

- **第一次用** —— `personal-secretary-v<版本>-full.zip`（完整版）：解压到任意文件夹，
  双击里面的 `私人秘书.exe`。**不用装 Python，不用装别的东西**，Windows 10/11 就行；
- **升级** —— `personal-secretary-v<版本>-patch.zip`（补丁包）：关掉程序，解压覆盖到
  软件文件夹里，再打开。配置、待办、已经下好的 QQ 一个都不动。

程序自己会看有没有新版本（**24 小时最多问一次**，只发一个 GET、不传任何数据），
有新版就在左下角出一行「🆕 有新版本」，点一下跳到上面那个下载页。
不想让它问：设置 → **界面与更新** → 关掉「启动时问一下有没有新版本」。

## 不用企业微信也能收

企业微信得先注册一个"企业"（哪怕只有你一个人）才能建群机器人，这一步劝退的人不少。
**不想注册的话，下面四个任选一个**，都是"填一个地址"的事：

| 你想怎么收 | 地址怎么拿 | 填哪 |
|---|---|---|
| 钉钉推到手机 | 钉钉里建个群（只有自己一个人也行）→ 群设置 → 智能群助手 → 添加机器人 → **自定义** → 复制 Webhook。安全设置选 **自定义关键词**，关键词填 `待办` | 设置 → 推送到手机 → 通用推送地址 |
| 手机**微信**收（安卓苹果都行） | 打开 [pushplus.plus](https://www.pushplus.plus)，微信扫码登录 → 它给你一条 `https://www.pushplus.plus/send?token=…` | 同上 |
| 飞书推到手机 | 飞书建个群 → 群设置 → 群机器人 → 添加机器人 → **自定义机器人** → 复制 Webhook | 同上 |
| iPhone 用 Bark | 装 Bark App，打开就给你一条 `https://api.day.app/…` | 同上 |

拿到之后：**设置 → 推送到手机 → 通用推送地址** → 地址整条粘进去 →
把开关打开。和企微一样，**光填地址不算，还得把开关打开** ——
这个开关默认是关的，不打开推送会退回控制台（屏幕上打印），手机上什么都没有。

三件事先说清楚，免得到时候以为坏了：

- **这四个都发不了附件**（图片原图、文档原件），只发正文。要连附件一起发到手机，
  只能用企业微信 —— 能发文件的接口只有它有。发不了的时候推送里会明说；
- 企业微信和通用地址**同时只能生效一个**：两个都开着的时候走企业微信；
- 地址里带着 token（有它就能往你手机上发东西）。程序**只会显示域名**，
  自检信息和意见反馈里也一样，不会把整条地址写出去。

## 🚧 现在还不周到的地方

下面这些不是"以后可能会做"，是**现在就是不行**。你先看一眼，免得装完才发现：

- **只支持 Windows**（10 / 11）。Mac 和 Linux 没做，也不打算做；
- **电脑得常开**。它靠电脑上那个 QQ 收消息，电脑关了就不收 ——
  这是"收 QQ 群消息"这件事本身要求的，不是我偷懒；
- **杀毒软件可能误报**。程序没做代码签名（签名要花钱），Windows 安全中心偶尔会拦一下，
  处理办法见下面那节「被杀软隔离了怎么办」；
- **图片原图和文档原件只有企业微信能发**。钉钉 / 飞书 / 微信 / iPhone 那几条只发文字；
- **只被一个朋友真机装过**。就我这台 Windows 11 加一个 QQ 小号，你电脑上的情况可能我见都没见过；
- **它用的是自带的 QQ，不是你电脑上那个**（互不影响，代价是多占约 244 MB 和一次下载）；
  QQ 版本对不上时要重下一份；
- **界面是我边学边画的**，风格不统一，有些边角没对齐；
- **手写体、拍歪的照片读得不太准**。印刷体和截图没问题；
  手写的建议先自己在手机上转成文字，再发给小号。

前面三条（Windows / 常开电脑 / 杀软误报）改不掉；后面几条我都会慢慢填，
你可以去 [Issues](https://github.com/Landercey/personal-secretary/issues) 看进度。

## 被杀软隔离了怎么办（**先看这个**）

**现象**：双击 `私人秘书.exe` 什么都没发生；或者弹出"文件不见了：app/ui/index.html…"；
或者 Windows 安全中心通知你"已阻止/已隔离"。

**原因**：这个程序是打包出来的、**没有代码签名**，杀软（尤其 Windows 安全中心）
对这类程序误报很常见 —— 而且本程序还会自动下载安装 NapCat，这个行为模式本身就
容易触发启发式判定。**它没有病毒**，源码就在这个仓库里，你可以自己看。

**三步解决**：

1. 打开 **Windows 安全中心 → 病毒和威胁防护 → 保护历史记录**，找到被隔离的文件，
   选「**还原**」（如果是"已阻止"，选"允许在设备上运行"）；
2. 把**整个软件文件夹**加进排除项：病毒和威胁防护 → 管理设置 → 排除项 →
   添加文件夹 → 选中 `私人秘书` 那个文件夹；
3. 还不行就用最新的**补丁包重新解压覆盖**一遍（`config.toml`、`data`、`napcat`
   都不在补丁包里，**你的配置和待办不会丢**）。

**让微软别再误报**（可选，但推荐做一次）：去
[微软的误报申诉页](https://www.microsoft.com/en-us/wdsi/filesubmission) 提交
`私人秘书.exe`，选 "Software developer" → "This file should not be detected"，
说明写"这是我自己写的开源工具，被启发式规则误报"。
**现成的英文文案和步骤**在 [docs/杀软误报申诉.md](docs/杀软误报申诉.md)。

**根治的办法**是买代码签名证书（几十到几百美元/年），签名之后杀软基本不再拦——
这是这类工具的通病，不是这个项目的特例。

## 打包成 exe（给不想装 Python 的人）

```bat
python tools/build_exe.py
```

跑完在 `dist\私人秘书\`，**81 MB**，整个文件夹复制走就能用：

```
私人秘书\
  私人秘书.exe      ← 双击这个。图标就是那条小肥鱼（打包时就嵌在 exe 里）
  用前必看.txt      ← 帮别人看的那 6 条
  _internal\        ← 程序自己的零件，别删
  config.toml  data\  plugins\  napcat\   ← 第一次双击之后才长出来
```

几个已经替你踩平的坑：

· **数据和程序在一起**：打包后"程序自己的目录"= exe 旁边那个文件夹，
  不是 `_internal`。卸载还是那两步：关自启、删文件夹。
· **桌面快捷方式自动建**：打包版第一次打开界面时自己建（已经有了就不碰）；
  打包脚本跑完也会立刻建一次。
· **快捷方式图标不会变成 Python 的图标**：指向 exe 自己带的那个小肥鱼
  （`私人秘书.exe,0`）。
· **把文件夹挪了地方**（比如从"下载"挪到 D 盘）也不怕：桌面快捷方式里存的是
  旧路径，双击一次新的 `私人秘书.exe`，它会自己把快捷方式修好。
· **重新打包会自动保住你的东西**：`config.toml` / `data` / `plugins` / `napcat`
  打包前挪到一边、打完挪回来（同盘改名，1.5 GB 也不会真复制）。
  但**打包时不能开着程序**（它锁着数据库，Windows 不让删）。
· **升级不用重新安装**：打完包会顺手产出一个 `补丁包-<时间>.zip`（约 40 MB，
  只含 `私人秘书.exe` 和 `_internal\`）。别人升级就是：关掉程序 → 把补丁包
  解压到软件文件夹里覆盖 → 再打开。**配置、待办、下好的 QQ 都不会动。**
· 打包脚本自带一道**体积闸门**（超过 400 MB 直接报错），防止哪天一个
  `import` 手滑又把 5 GB 的机器学习库拖进来（第一次打包就这么炸过，见 CONTRACT.md 第 12 步）。

## 界面能干什么

打开 `python run.py --ui`（或者双击桌面的「私人秘书」），左侧一列就三件事：

| 按钮 | 干什么 |
|---|---|
| **＋ 新建待办** | 粘贴一句话，时间和地点自动认出来 |
| **⟳ 同步** | 立刻拉一遍课表订阅，变成待办 |
| **⚙ 设置** | 推送时间、企业微信 Webhook、QQ 群号、AI、课表、过滤强度……**全在这里改** |
| **📱 QQ 接收** | 启动/停止后台、扫登录二维码、开机自启 —— 点一下右栏就出来 |

左侧分组：今天 / 明天 / 本周 / 下一周 / 逾期 ｜ 全部未完成 / **已完成** / 已归档 / 废件箱。
**没写时间的待办算「今天」**——你不写时间就等于"今天要做"。不然「拿快递」
这种随手记的只有点开「全部未完成」才看得到，你会以为它丢了。
（只算进「今天」：明天/本周/逾期都不算，它没时间，凭什么算过期。）
右上角有个**搜索框**（标题、正文、地点、原话都搜得到）。
搜索**只在当前分组里找** —— 在「今天」里搜就只搜今天的，
标题旁边会写着"只在「今天」里找"。
点开一条待办能**改标题、时间和地点**（解析错了不用重新发一遍），
附件能看名字、能点「打开」，是图片还会出缩略图。
右栏右上角有个 **✕** 可以随时收起来。

**左下角会告诉你收消息的进程到底活没活**：
`✅ 登录号 xxx｜收到 42` 是正常；`⚠️ QQ 接收已经 N 分钟没动静了`（橙色）
说明那个进程没在跑或者 NapCat 掉线了 —— 这就是"我发了消息怎么没反应"的答案。
左下角还有一行 **内存**：`内存 62%｜本程序 150 MB`（鼠标悬停看界面/后台各占多少）。
**左下角每一行都能点**，点哪儿跳哪儿：

| 那一行 | 点它去哪 |
|---|---|
| ✅ 登录号 / ⚠️ 后台没在跑 | 「📱 QQ 接收」那一栏 |
| ⚠️ 推送还没配好（只在没配好时出现） | 设置 → 企业微信或通用推送地址（跳到你还没弄完的那一段） |
| 内存 34% · 184 MB | 点不动它 —— 悬停能看到界面 / 后台各占多少 |
| 推送 07:30 / 21:30 | 设置 → 什么时候推 |
| 11 个群 | 设置 → QQ 接入 |
| 插件 N 个 | 插件面板（看有几个、哪个坏了、去它的设置） |

**QQ 也能从界面里管**：点左下角「📱 QQ 接收」，右栏就是那一块

- 「启动 QQ」：后台常驻（一个进程同时干**收消息 + 定时推送**两件事）
- **登录二维码直接显示在里面**（用手机 QQ 扫）。约 2 分钟过期，
  过期了点「重新出码」换一张
- 「停止后台」
- **开机自启**：开了以后每次开机它自己在后台跑，不用每天手点一次

（第一次「启动 QQ」会先自动下载安装 NapCat，约几十秒。要在
设置 → 收消息 → QQ 接入 里填一次"要登录哪个 QQ 号"。）

**第一次那一装，界面上能看见到哪一步了**：那一块会自己变成
「⏳ 正在装 NapCat… / 已经等了 X 分 Y 秒」，装完自己消失。
这几分钟是官方安装器在下 QQ（约 300 MB），**它自己会报进度**
（`下载 QQ 26% (78MB/300MB)`），所以有进度条 —— 而且报的不是假的，是它说的数。
它不报数的那几段（解压之类）就不画进度条，只写"已经等了多久"。
装的时候「启动 QQ」按钮是灰的，**别重复点**。
整个过程不会蹦出黑色终端窗口。

（NapCat 自己的输出不丢，写在 `napcat\napcat.log` 里。以前它是在一个终端窗口里
滚动显示的，而且**中文全是乱码**——所以现在既不弹窗，也能查；二维码永远看我们
界面上那一张。）

**没填 QQ 号就点「启动 QQ」会卡住** —— 所以现在会**先拦住你**：
那一页会弹出一块橙色提示，告诉你缺哪一项、去哪儿填，启动按钮同时变灰。
真出了别的毛病，下面还有一个「上次启动的输出」可以看后台到底说了什么。

**全装在一个文件夹里**：程序、`data`（你的待办）、`napcat`（QQ 本体）都在
同一个目录下。**卸载 = ① 关掉开机自启 ② 删掉这个文件夹**，两步，不留东西
（设置 → 数据与资源 底部写着具体路径）。

收 QQ 消息那套（QQ 本体 + NapCat）也在同一个文件夹里，装完在 `napcat\`，
**约占 1.5 GB**（下载量约 300 MB，解开来就这么大 —— 里面是一整个 QQ）。
它跟你电脑上原本装的 QQ 是**两份，互不影响**；删文件夹就一起清掉。

做完的事不会消失：「已完成」分组里找得到，还能一键撤回来。
点错的「这不是待办」也找得回来：废件箱里和"被拦下的原文"放在一起，能点「恢复」。

**移出都只有一个人目的地：回到「全部未完成」。** 完成、归档、误判三种都能移出，
移出之后不用选去哪 —— 它自己按截止时间回到该去的分组（今天/本周/逾期…），
没写时间的就只在「全部未完成」里。想改到别的日子用「改内容」，那是两件事。
（废件箱里"被拦下的原文"不是待办，所以没有移出这一说。）

**把文件或一段字拖进窗口**，右边会弹出「这个怎么处理？」：
读里面的字变成待办 / 只看它写了什么 / 算了。拖进来的文件大小上限默认 12 MB
（网页拿不到真实路径，内容要摊成文本传过去），更大的用 `python run.py --file 路径`。
**从桌面拖过来的如果是快捷方式（.lnk）也没关系** —— 会自动跟到它指向的那个文件。
读不出内容时，会直接告诉你原因（旧版 Office、扫描件、不支持的格式……），
不用猜。

**能读的文件类型**：Word / PPT / Excel / PDF / 图片（系统自带 OCR）/
**压缩包（.zip，里面的文件挨个读）** / **思维导图（.xmind）**。
视频、旧版 `.doc/.ppt/.xls`、`.rar/.7z` 暂时不支持 —— 拖进去会告诉你
该怎么绕过去（比如"另存为 .pptx 再发一次"）。

**小号收件箱**（设置 → 收消息 → QQ 接入 → 小号收件箱）是**全盘接收**的：
你发给它的东西不过滤闲聊、不过滤碎片，**连文件里读出来的字也当待办**。
别的地方（群消息、别人发的文件）会严格过滤 —— 那边噪声多，不严不行。

设置面板里的每一项都带一句人话说明，改完点「保存」会**写回 config.toml**
（只改你动过的那一行，你自己写的注释不会被冲掉）。
**「保存」就在右栏最底下，一直跟着你**（不用滚回顶上找），有没保存的改动会
写成「有改动还没保存」；直接叉掉窗口的话会先问你一句，不会默默把你的改动作废。

设置分成四个标签页，不用在一长条里翻：

| 标签页 | 里面有什么 |
|---|---|
| 推送到手机 | 企业微信机器人、通用推送地址（钉钉/飞书/PushPlus/Bark）、什么时候推 |
| 收消息 | QQ 接入、用大号还是小号、课表 |
| 看懂消息 | AI 增强、识别与过滤、文件解析 |
| 数据与资源 | 数据保留、资源占用、标题规则 |

一般不用动的东西（文件解析细节之类）折在每段底部的「高级」里。

**「AI 增强」是可选的，默认关着**：关着的时候走纯规则解析——不联网、不花钱、
任何内容都不会传出去。想开的话在「看懂消息 → AI 增强」里填三样：
接口地址（填到 `/v1` 为止，本地 Ollama 就是 `http://127.0.0.1:11434/v1`）、
密钥、模型名，然后把**两个开关**打开（`enabled` + `allow_upload`）。

![AI 增强设置](docs/images/ai-settings.png)

它是给**长通知**用的：群里发一大段考核安排，规则会切出"字数不少于 3000"
这种碎片，AI 能归纳成"交论文（12-20 前）"+"随堂测验（12-27 09:00）"。
开的两个开关是故意的——第二个 `allow_upload` 明确写着"开了之后消息原文
会离开这台电脑"，不替你决定要不要传出去。

**AI 连不上不会让你少收东西**：那次会自动退回规则解析、照常推送，
原因写在 `data\ai-status.json` 里。AI 归纳出来的待办在推送里带【AI】标记，
末尾一句"【AI 整理，可能有误】"——原文和附件永远留在本地。
**监听地址、端口、路径、令牌**这四项标着「程序管着」，默认点不动 ——
它们要跟 NapCat 的配置严格一致，单方面改会让 QQ 静默收不到消息。
确实要改的话点下面的「确实要改」就能编辑。

第一次打开会弹一个风控提示：用大号还是小号，代价不一样。看完点「我知道了」就不再弹。
中间顶部还有一张"还没弄完这几步"的清单，点哪一条直接跳到对应的设置。

**时间相关的设置不会一上来就问你**：推送时间先用 07:30 / 21:30 跑着，
等你**第一次真的在手机上收到推送**之后，界面才提醒你"想换时间点就点这里"。
课表的"开学第一周"同理 —— 只有你导入的课表里真的写了单双周，才会提醒你填。

### 插件：拖进去就装好

左下角点「插件 N 个」进那一栏，里面能看到装了哪几个、哪个坏了、坏在哪儿。

**装插件不用去文件夹里翻**：把那个 `.py` 直接拖进窗口，右边弹「这是个插件」，
点「装成插件」——

- 程序**当场试着加载一次**，坏的（语法错、没写 `register()`）当场告诉你哪儿坏了，
  **文件不会留在你文件夹里**；
- 有同名的**不会覆盖**（那可能是你自己改过的）；
- 装完**要重开一次程序**才生效；
- 底下有「打开插件文件夹」，删掉文件就是卸载。

⚠️ **插件就是一段 Python 代码，跑起来权限和你自己写的程序一样** ——
能读你的待办、能联网、能删你的文件。**只装你信得过来源的**。

（**没有做"插件应用商店"**：那得先有一台服务器，而且"上架"会让用户误以为
"审核过 = 安全"，这个审核做不了。以后真要做的话，是仓库里放一个
`plugins-index.json`，界面从 GitHub 读，不需要自己的服务器。）

### 意见反馈：一键生成一段**脱敏过**的话

设置面板最底下有「📮 用着哪里不对？点这里写反馈」。写一句你遇到的事，
点「生成反馈」，下面出一整段话，**复制走**贴到 QQ 群或者 GitHub Issue 就行。

那段话自动带着版本、系统、内存、收消息状态、推送记录、插件情况和后台日志尾巴，
**并且自动把号码打码**（QQ 号、群号只留后 4 位，Webhook 的 key 全打掉）——
复制之前程序已经替你处理过了。

只有勾了「附带最近 5 条被拦下的原文」才会带上群名和消息内容（排查"这条怎么没进来"
时才有用），**只发给我一个人时再勾**。

（**不做"点一下就自动上报"**：一按按钮就把你的群名、消息原文传出去，
对开源小工具来说是减分项。你复制、你看过、你再决定发不发。）

## 现在就能跑

**不想装 Python 的话**：拿打包好的文件夹，双击 `私人秘书.exe` 就行
（怎么打见上面「打包成 exe」）。

自己跑源码的话（Windows + Python 3.11 以上）：

```bat
python run.py --selftest          检查契约和环境
python run.py "明天下午三点交作业"  录一条
python run.py --read 照片.jpg     只看这个文件能提出什么字，不入库
python run.py --file 作业.pptx    把一个文件变成待办
python run.py --list              看未完成
python run.py --list junk         看废件箱（没收下的原文都在这里）
python run.py --digest            生成一份汇总打印出来
python run.py --push              把汇总真正推出去（企业微信或通用地址）
python run.py --check-push        检查推送通道配置（不发消息）
python run.py --next-push         看下一次什么时候推、有没有错过的
python run.py --schedule          启动定时推送（Ctrl+C 停止）
python run.py --setup --account 你的QQ号   只装 NapCat（约 2.5 分钟）
python run.py --deploy --account 你的QQ号  装 + 启动（先起接收端再起 QQ）
python run.py --ui                打开界面
python run.py --shortcut          在桌面建快捷方式
python run.py --check-qq          看 QQ 接入的配置和状态
python run.py --qq                启动 QQ 接收（Ctrl+C 停止）
python run.py --done 3            标记某条完成
python run.py --stats             看统计
python run.py --plugins           看装了哪些插件、哪个坏了
python run.py --sync              拉一遍课表订阅，变成待办
```


## 架构

```
[来源] ──► [理解] ──► [存储] ──► [输出]
```

四段之间**只通过契约层定义的四种数据格式通信**，不许互相 import 内部实现 ——
这条由 `tests/test_contract_integrity.py` 自动检查，破坏边界会直接测试失败。

```
app/contracts/   四种数据格式 + 五个接口
app/sources/     手动录入、QQ 群消息、小号收件箱
app/pipeline/    闲聊过滤、繁简归一、规则解析、管线
app/store/       SQLite
app/sinks/       企微群机器人、控制台
app/runtime/     配置中心（所有阈值集中在这里，代码里不写裸数字）
```

## 版本与升级

**版本号写在三个地方，都是同一个来源**（`app/version.py` 里的 `VERSION`）：

| 在哪看 | 长什么样 |
|---|---|
| 设置页最上面一行 | `v0.1.0（构建 2026-10-12 10:30｜提交 abc1234）` |
| `私人秘书.exe --version` | 同上 |
| 意见反馈那段话的第一行 | 同上（报问题时不用你翻，程序自己带上） |

**升级不用重装**：每次打包会产出 `补丁包-v0.1.0-<时间>.zip`（约 40 MB，
只含 `私人秘书.exe` + `_internal\` + `build-info.txt`）。升级三步：

1. 关掉程序；
2. 把补丁包**解压到软件文件夹里覆盖**（`config.toml`、`data`、`plugins`、
   `napcat` 都不在补丁包里，所以配置、待办、下好的 QQ 一个都不动）；
3. 再打开 —— 设置页顶上那行版本号就变了。

**发新版时作者要做的事**：改 `app/version.py` 的 `VERSION` → 在
[CHANGELOG.md](CHANGELOG.md) 顶上加一段 → 跑 `python tools/build_exe.py`
→ 打 tag、发 Release（**不放开草稿，用户就收不到"有新版本"**）。
完整步骤和两个坑写在 [CONTRACT.md](CONTRACT.md) 的「发版流程」。
